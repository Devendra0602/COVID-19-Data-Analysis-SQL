# COVID-19 Data Analysis using SQL

## 📌 Project Overview
This project analyzes global COVID-19 data using SQL to understand infection rates,
death trends, and vaccination progress across countries and continents.

## 🧠 Business Problem
Governments and health organizations need insights into:
- Infection spread patterns
- Mortality rates
- Vaccination coverage
- Regional performance comparison

## 📊 Dataset
- Source: Public COVID-19 dataset
- Tables Used: CovidDeaths, CovidVaccinations
- Data Cleaning: NULL handling, data type casting, filtering non-country records

## 🛠 Tools Used
- SQL Server
- Advanced SQL (CTEs, Views, Window Functions)

## 🔍 Analysis Performed
- Total cases vs total deaths
- Infection rate compared to population
- Country and continent-level death analysis
- Global COVID statistics
- Rolling vaccination analysis using window functions

## 📈 Key Insights
- Certain countries experienced significantly higher infection rates
- Death counts vary widely across continents
- Vaccination rollouts show steady cumulative growth over time
- Global death percentage remains relatively low compared to total cases

## 📂 Files Included
- `Covid_Data_Analysis.sql` – SQL queries with comments and structured analysis
